# Mouse Mover

A lightweight Python utility that automatically moves the mouse and performs a click every 60 seconds.

## Features

✅ Automatically moves the mouse every minute  
✅ Performs a mouse click to simulate activity  
✅ Returns the mouse to its original position  
✅ Runs continuously until stopped  
✅ Simple and lightweight

## Requirements

- Python 3.8+
- PyAutoGUI

## Installation

Clone this repository:

```bash
git clone https://github.com/<your-username>/mouse-mover.git
cd mouse-mover
```

Install the required dependency:

Shell
```bash
python -m pip install pyautogui
```
##Usage

Run the script:
```bash
python mouse_mover.py
```
How It Works

The script:

Captures the current mouse position.
Moves the mouse slightly.
Performs a mouse click.
Returns the cursor to its original position.
Waits 60 seconds.
Repeats the process until stopped.
Stopping the Program

To stop the script, press:

Plain Text
Ctrl + C

in the terminal window where the program is running.
